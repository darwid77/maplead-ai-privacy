# Privacy Policy for MapLead AI

Last updated: 2025

MapLead AI is a Chrome extension developed by Grow Labs.

## Information Collection

MapLead AI processes publicly visible business information displayed on Google Maps pages selected by the user.

## Data Processing

All extracted information is processed locally within the user's browser.

## Data Sharing

MapLead AI does not sell, rent, transfer, or share user data with third parties.

## Remote Servers

MapLead AI does not transmit extracted lead data to external servers.

## User Control

Users are responsible for any data they export using the extension.
